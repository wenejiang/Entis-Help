# 流量监测图

---

### 1：功能描述

- 在此界面，可以重点监测作业罐，并显示作业罐的流速和液位实时趋势图

### 2：如何开始使用

- ![](assets/9cbf9dbd2c5d84a8-20261015000317-lpgmgfh.png)
- ![](assets/0db3630734b49a32-20261015000317-c0foviz.png)

### 3：操作说明

点击此按钮后，会自动把当前正在作业的罐根据进出作业的罐分别添加到左右二列，左边列为进罐作业，右边列为出罐作业自动添加依据条件：

- 被设置为进出罐作业的罐
- 自动状态，但监测到有进出流速的罐

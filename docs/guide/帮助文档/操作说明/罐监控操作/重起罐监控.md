# 重起罐监控

### 1:功能描述

- 重起罐监控模块,一般情况下,如果更改了配置,系统会提示你是否重启罐监控模块,如果用户当时未选择重启,后面又想重启使配置改动生效,则可以使用此功能.

### 2:如何开始使用

- 依次打开菜单 "罐监控操作" => "重起监控"，如图：

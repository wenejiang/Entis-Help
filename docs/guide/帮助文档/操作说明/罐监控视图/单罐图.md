# 单罐图

---

### 1:功能描述

查看单个罐的详细信息，如罐配置值，液位，温度，密度，体积，质量，修正，多点密度，多点温度，实时趋势图等各类数据

### 2:如何开始使用

依次打开菜单 "罐监控视图" => "单罐图"，如图：

在左上角罐列表中选择要显示的罐，这里的罐列表中的罐也受上面工具栏中的罐过滤选项控制：

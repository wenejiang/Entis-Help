# 如何在现有的数据库服务器上启用Sa帐号

如果在安装过程中选择“Windows 身份验证模式”,没有选择混合模式,则 SQL 身份验证被关闭,sa帐号也被禁用,要启用SA帐号,需要安装SQL Server Management Studio 对象资源管理器**,**并执行更改命令**,**过程比较麻烦**,**不容易掌握**,**

**建议采用如下任意一种方案**

- **重新安装SqlServer的方式比较方便,先在控制面板中删除SqlServer,然后再执行**SqlServer**安装程序**,**此时再设置为混合模式**,**并设置**Sa**的密码即可**,
- **先在控制面板中删除SqlServer,,然后**重新执行Entis主程序安装文件,在安装过程中勾选"**是否按照默认配置自动安装SqlServer2017数据库**",勾选后,默认安装的数据库实例有默认的sa帐号

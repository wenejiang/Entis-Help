# Modbus输出设置

---

### 1：功能描述

    实现罐数据的Modbus输出功能,可以同时几路输出

### 2：如何开始使用

首先在系统初始化向导中要选择罐监控输出模块，否则无法运行，界面上也无法看到相关菜单和功能。

### 3：操作说明

在顶部工具栏最左侧，开关按钮中选中开启 

具体使用方法参考罐监控配置下的通讯配置功能

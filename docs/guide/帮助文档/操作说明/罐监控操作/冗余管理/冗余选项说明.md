# 冗余选项说明

---

### 1:功能描述

    配置冗余应用中的一些重要选项．

### 2:如何开始使用

依次打开菜单 "罐监控操作" => "冗余管理" => "更多选项"，如图：

- 定时命令：选择后，在从机状态下，定时命令自动禁用，如定时测水，测密度等定时任务，在主机执行即可，从机同时执行，反而影响系统稳定性
- 仪表操作：一般从机在执行仪表操作时，是通过虚拟通道由主机代理执行，效果不如直接在主机执行，所以可以选择此项，直接禁止在从机操作
- 数据输出，默认情况下，主机端和从机端都会对外输出数据，但如果数据接收端同时只能接收一路数据的话，可以选择此项，让从机端不输出数据。

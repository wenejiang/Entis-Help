# 数据库迁移说明

### 简介

         有时候安装完系统，有现成的组态备份，不需要重新组态，所以直接把原来的组态备份数据迁移过来即可，大大节省工作量. 具体执行步骤是备份数据库-还原数据库的过程,使用工具为附带的DBTools小工具.

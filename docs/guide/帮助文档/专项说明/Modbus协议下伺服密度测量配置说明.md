# Modbus协议下伺服密度测量配置说明

‍

### 需要配置项说明

##### 停止测量-并返回液位开关（可选配置项）

    当测量失败或中途取消测量时，写入命令，返回液位测量，如未配置，无法中途停止伺服测量

##### 伺服密度测量开关（必须配置项）

    写入命令，执行多点密度测量

### 平均密度地址（可选配置项）

    读取平均伺服密度，计算重量时需要用到

### 平均密度状态地址（可选配置项）

平均伺服密度状态

### 伺服密度执行状态位（必须配置项）

> 0：表示未执行，执行伺服密度前，需要判断此值为0，才会执行伺服密度测量1：表示正在执行2：表示执行完成

### 测量高度点（自动重复项）（可选配置项）

    使用此项配置，一项可自动重复多次，也可以用单点的读取项来代替配置
    使用此项的好处是只在伺服密度测量完毕后，读取一次，不影响平时的扫描读取。

# 罐历史明细表

---

### 1:功能描述

根据选定的罐，设定的开始时间和结束时间，可以查看各个罐的历史记录信息，并可导出为 Excel 文件。

### 3:操作说明

选择要查询的罐，设定好开始时间和结束时间，点击按钮 "查看"，就可以以分页的形式显示历史记录：

当前只支持Excel方式的导出,点击"导出"按钮,显示如下的界面,选择好要导出的文件位置,设置好要导出的字段,点击确定,稍等即可导出数据,具体导出时间根据数据量大小不同有所区别

# 冗余管理配置说明

---

### 1:功能描述

    开启关闭冗余，配置冗余各项参数以及冗余通道切换等操作

### 2:如何开始使用

依次打开菜单 "罐监控操作" => "冗余管理"，如图：

###### a:冗余管理主界面

b：冗余通讯配置界面：

### 3:操作说明

**打开/关闭冗余功能**：点击主界面左上角开关选项，如显示 "已开启"，表示冗余功能开启，但实际生效需要重启软件；显示 "已关闭"，则重启后冗余功能关闭。

# 安装过程提示启用PowerShell出错，导致无法完成SqlServer安装

---

### 一：解决方案一

    一般情况下，在Windows系统中自带PowerShell,所以正常系统不会有这样的提示，如果出现了这样的提示，说明系统文件有损坏或是被阉割过的系统
尝试手动安装PowerShell下载地址：[https://docs.microsoft.com/en-us/powershell/scripting/wmf/setup/install-configure?view=powershell-7](https://docs.microsoft.com/en-us/powershell/scripting/wmf/setup/install-configure?view=powershell-7)根据不同版本下载相对应的安装版本

### 一：解决方案二

    重新系统，这是最佳推荐方法

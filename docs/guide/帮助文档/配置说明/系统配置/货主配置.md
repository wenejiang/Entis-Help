# 货主配置

---

### 1:功能描述

- 对货主信息的新增,修改,删除.

### 2:如何使用：

依此打开菜单 "系统配置" => "货主配置"。此处不管系统处于什么状态，都不需要输入操作员密码，即可打开，界面如图：

### 3:操作说明

点击按钮 "新添"，打开添加窗口，如图：

选中要修改的记录，点击 "修改" 按钮，显示修改界面，如图：

选中要删除的记录，点击 "删除" 按钮，显示删除确认框，如图：

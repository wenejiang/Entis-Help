# 数据库同步复制说明

### 简介

    冗余系统二台主机的组态数据必须一致，如果分别在二台电脑上组态完成，工作量较大，且容易出错，所以最佳作法，就是在一台电脑上组态完成后，然后把数据库使用备份还原的方式，同步到另一台电脑

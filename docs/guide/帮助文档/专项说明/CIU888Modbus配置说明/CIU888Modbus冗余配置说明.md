# CIU888Modbus冗余配置说明

---

### 配置第一步

在通讯配置模块中找到 CIU 参数配置选择，然后选择 CIU 类型为 CIU888，然后边上的配置按钮就会变为可用状态，如下图：

### 验证第二步

在可选通讯口这一列选择备用通道，并点击切换按钮，系统将切换到备用通讯口通讯。请稍后检查相应 CIU 的冗余显示状态，完成后，再选择主通道，再点击切换按钮，切换回来即可，如下图：

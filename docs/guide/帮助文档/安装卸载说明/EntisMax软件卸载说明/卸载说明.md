# 卸载说明

**以下为卸载本程序的过程说明,当前示例操作系统是Win7,其他系统请对应参照**

---

1:进入控制而板的程序和功能项，或者叫添加/删除程序项。

![](assets/177e71213c034de3-20261015000315-z6i1d5e.png)

2:找到Entis
MAX项，选择删除或卸载。

![](assets/edf60c27dfd8feb8-20261015000315-xf05o6k.png)

3:系统将显示卸载过程，请稍待，程序将被从系统中清理掉，包括安装的数据库，如数据比较重要，请卸载前做好备份。

![](assets/ba7037a79afe47de-20261015000315-3etlnt1.png)
